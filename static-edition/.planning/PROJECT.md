# 나의 창작실

## What This Is
개인용 비공개 창작 웹앱. 사용자 본인만 사용하며 회사·제품·의료기기 맥락은 제외한다. 집·회사·휴대폰에서 같은 서버의 프로젝트와 자료를 이어 쓰는 방향이며, 현재는 로컬 개발·검수 후 외부 배포를 별도 승인받는다.

## Core Value
나의 자료·대본·이미지 편집 상태를 잃지 않고 한 작업실에서 이어 쓴다.

## Requirements
### Validated
아직 사용자 검수 전.
### Active
프로젝트 저장, 대본·스토리보드, 이미지 작업, 썸네일 편집, 계정 인증과 반응형 화면.
### Out of Scope
타 사이트 소스·디자인·전용 프롬프트 복제, CVT200 및 회사 업무, 공개 서비스·다중 사용자 가입, 자동 외부 배포·구독·유료 AI 호출.

## Constraints
Node.js 24 내장 HTTP·SQLite·crypto로 로컬 서버 저장 구조. 외부 생성 API는 연결 전임을 표시한다. API 키가 없어도 수동 편집·로컬 대본 분할·자료 관리·PNG 출력은 실제 작동한다. 로컬 테스트 성공을 실제 원격 동기화 성공으로 표현하지 않는다.

## Key Decisions
- 개인용 및 다기기 사용: 사용자 확정(2026-10-18).
- 사용자의 진행 승인 범위: 기능 명세와 화면 구성부터 시작하여 로컬 구현·검수. 배포·업로드·유료 호출은 별도 승인.
- 자체 구현 중심, REA는 현재 사용하지 않음.
- 1차 제작물은 로컬 검수 가능한 앱과 소스. AI 생성·원격 배포는 다음 단계 대기.

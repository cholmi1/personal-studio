# v0.4 AI 연결·배포 준비

승인 범위: 코드·배포 설정 준비와 로컬 검수. 실제 배포·결제·실제 AI 키 사용 없음. 기존 기능·데이터 보존.

1. 키 서버 암호화 보관 / 환경변수 우선, Gemini 텍스트+이미지 입력 / OpenAI 이미지 생성·편집, 한도와 오류 처리.
2. 원격 최초 설정 토큰, HTTPS·Origin·Secure 쿠키, 영구 볼륨 / 단일 인스턴스. Docker·Railway·Render 사전 설정.
3. AI 설정 화면, 후기·상세 설계·장면·프롬프트·이미지 탭 AI 연결. 호출 전 외부전송·비용 확인.
4. API 자동 테스트와 모의 제공자 브라우저 통합검수. 모의는 검수 전용이며 배포 코드에 결과 하드코딩 금지.
5. 설명서·ZIP·GitHub 소스 보관. 공유 작업 로그는 별도 요청시에만 기록.

한계: Vercel 직접 배포 미지원(현재 영구 SQLite·파일 구조). Cloudflare+Supabase 전환範囲 제외. Docker 미설치 시 빌드 검증 불가를 명시. 실 AI 품질·요금·모바일·원격 백업 검증은 키 적용/배포 이후 별도.

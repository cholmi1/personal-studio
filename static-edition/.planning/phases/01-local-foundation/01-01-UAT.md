# 사용자 확인 안내

2026-10-18 로컬 시제품의 개발자 검수 통과. 아래 사용자 인수 검수는 아직 미실시입니다.

1. http://127.0.0.1:4318/ 에서 이름·로그인 이메일·12자 이상 비밀번호를 직접 설정합니다. 비밀번호 찾기는 아직 없으므로 안전하게 보관합니다.
2. 새 작업을 만들어 대본을 입력하고 로컬 분할을 누릅니다. 이는 AI 작성이 아닌 규칙 기반 분할입니다.
3. 저장을 누르고 새로고침해 내용이 남는지 확인합니다. 서버 저장은 수동이며 자동저장이 아닙니다.
4. 이미지·썸네일에서 본인 사진과 문구를 넣어 PNG를 내려받습니다.
5. 백업을 내려받고 가져오기에서 별도 작업으로 복원합니다. 백업에는 원본 이미지가 포함되므로 안전하게 보관합니다.
6. 서버가 꺼져 있으면 압축을 푼 뒤 시작.cmd를 실행합니다. 실행창을 닫으면 서버가 멈춥니다.

휴대폰이나 다른 PC에서는 이 127.0.0.1 주소를 쓸 수 없습니다. 다기기 사용은 별도 승인 후 비공개 HTTPS 배포가 필요합니다.

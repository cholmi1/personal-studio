# 로컬 구현 결과

완료: 2026-10-18

## 구현
- Node.js 24 내장 HTTP·SQLite·암호화 기능 기반, 외부 패키지 없이 인증·저장·버전 충돌·이미지 자료·백업/복원 구현.
- 한국어 프로젝트 목록, 대본 편집과 명시적인 로컬 장면 분할, 장면 순서/메모, 이미지 배경·텍스트 레이어·PNG 출력 구현.
- 입력값을 확정한 뒤 저장하고 버튼 DOM을 안정적으로 유지하도록 저장 경로 보완.
- 원본 서비스의 내부 코드·브랜드·자산은 복제하지 않음.

## 검증
- 실제 설치된 Node.js 24.20에서 서버 자동 테스트 11/11 통과, 공개 JS 6개 문법 검사 통과.
- 실제 브라우저에서 계정 설정·로그인, 대본 3개 장면/계획 길이 30초, 서버 저장 및 새로고침, 이미지 업로드와 문구 편집 검수.
- PNG 파일 헤더 실측: 가로 1280×720, 세로 1080×1920. 영상 출력이나 실제 음성 30초를 뜻하지 않음.
- 백업 JSON에서 대본 119자·장면 3개·레이어 1개·원본 이미지 확인. 가져오기에서 새 프로젝트와 새 이미지 ID로 복원됨을 확인.
- 숫자 Y 입력 직후 마우스 저장으로 서버 버전 2 및 Y=431 보존 확인. 별도 격리 검수에서 상태 버튼/헤더 버튼/Ctrl+S 경로도 확인.
- 부모 검수 브라우저 pageerror 0건.
- 독립 검토에서 로컬 시제품 기준 필수 수정 문제는 발견되지 않음. 인터넷 서비스 보안 인증이나 배포 검증은 아님.

## 실행·정리
- 사용용 로컬 실행: http://127.0.0.1:4318/
- 사용용 데이터: %USERPROFILE%\.aside\u\0\personal-studio-data. 본인 소유자 계정은 아직 미생성.
- 검수용 8426 서버 종료, 검수 계정/자료 DB 폴더 삭제. 검수 자격증명은 저장소·Vault·배포본에 포함하지 않음.
- 시작.cmd는 같은 Aside 데이터 위치를 사용하며, 해당 계정 폴더가 없는 환경에서는 앱 폴더 .data로 대체함.

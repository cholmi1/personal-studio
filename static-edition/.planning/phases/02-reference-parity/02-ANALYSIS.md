# Phase 2.5 참조 앱 비교 분석 및 적용 범위

작성: 2026-10-18 · 근거: 사용자 제공 참조 화면 6장(스토리보드, 3.0 에디터, 애니 실사화, 실사 애니화, 시그니처 이미지 생성, 디렉터 캔버스)과 참조 사이트 공개 작업실 화면(9개 도구 설명, 프롬프트 헬퍼 분류). 로그인 후 내부 동작은 확인하지 않음.

## 원칙
- 참조 앱의 코드·디자인·브랜드·전용 프롬프트 문구는 복제하지 않는다. 기능 개념만 참고하고 화면·문구·프롬프트 조각은 자체 작성한다.
- AI 없이 실제로 동작하는 기능은 이번에 구현한다. AI가 필수인 기능은 결과를 흉내 내지 않고 'AI 미연결'로 표시한다.
- 개인용·로컬 우선 구조, 서버 저장·백업·충돌 감지 등 기존 강점은 유지한다.

## 기능별 비교와 결정

| 비디오 / 오디오 | 영상 생성, 립싱크·배경음악 | 없음 | 미연결 표시 | 별도 승인 후 |

## 참조 앱보다 나은 점으로 유지할 것
프로젝트 단위 서버 저장, 버전 충돌 감지, 원본 이미지 포함 백업/복원, 자료함, 본인 전용 로그인, 크레딧 차감 없음, 외부 전송 없음.

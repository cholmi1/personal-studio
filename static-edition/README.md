# 나의 창작실 정적판 v1.0

서버와 로그인 없이 **브라우저 안에 작업을 저장**하는 개인용 창작 웹앱입니다. 화면 파일만 올리면 되므로 Cloudflare Pages 같은 무료 정적 호스팅에 배포할 수 있습니다. 서버판(Node + SQLite)은 같은 저장소의 루트에 그대로 있습니다.

## 서버판과 달라진 점
| | 서버판 | 정적판 (이 폴더) |
|---|---|---|
| 작업·이미지 저장 | 서버 디스크 | **이 브라우저의 IndexedDB** |
| 로그인 | 소유자 계정 | 없음 |
| AI 키 | 서버에 암호화 보관 | **이 브라우저에 보관(암호화 없음)** 또는 탭을 닫으면 삭제 |
| AI 호출 | 서버가 중계 | **브라우저가 Google·OpenAI로 직접 호출** |
| 기기 간 이어쓰기 | 같은 주소로 접속 | **자동 동기화 없음, 백업 파일로 옮김** |
| 호스팅 비용 | 월 몇 달러 이상 | 무료 정적 호스팅 가능 |

## 꼭 알아둘 점
- 작업은 **이 기기의 이 브라우저에만** 있습니다. 사이트 데이터를 지우거나 다른 브라우저로 열면 보이지 않습니다. 중요한 작업은 작업 화면의 "백업"으로 파일을 내려받아 두세요.
- 다른 기기에서는 "백업 파일 가져오기"로 불러옵니다. 서버판에서 내려받은 백업도 가져올 수 있습니다.
- 사이트 주소는 공개 주소입니다. 하지만 작업 내용은 각자의 브라우저에만 있고 서버로 전송되지 않으므로 다른 사람이 내 작업을 볼 수 없습니다.
- AI 키는 암호화되지 않은 채 브라우저에 저장됩니다. 제공자 화면에서 **사용 한도(예산)를 정한 제한 키**를 만들어 쓰고, 공용 PC에서는 "이 브라우저에 키 기억하기"를 끄거나 사용 후 키를 삭제하세요. 작업 백업 파일에는 키가 들어가지 않습니다.
- 하루 AI 요청 한도는 이 브라우저에서 세는 횟수일 뿐 금액 상한이 아닙니다.

## 기능
디렉터 캔버스(스케치·화풍), 시그니처 이미지 생성, 실사 애니화, 애니 실사화, 멀티 이미지 에디터, 스토리보드, 그리고 추가 기능인 상세페이지 제작, 이미지·썸네일 편집, 대본·장면, 프롬프트 작업대. 직접 편집·스케치·장면 분할은 AI 없이 쓸 수 있습니다. AI 생성·변환은 실행 전에 Google·OpenAI로 직접 전송되는 내용과 비용을 확인합니다.

## 내 PC에서 미리보기
Node.js 20 이상이 있으면 됩니다. 별도 설치는 없습니다.
1. 이 폴더에서 `node tools/serve.mjs` 를 실행합니다.
2. 브라우저에서 http://127.0.0.1:4400 을 엽니다. 실제 배포와 같은 보안 헤더(`public/_headers`)가 적용됩니다.

## 배포
`DEPLOY-PAGES.md`를 보세요. 빌드 명령은 없고, `public` 폴더 전체가 배포 대상입니다.

## 검증
- `npm test` (`node --test tests/*.test.mjs`): AI 요청 형식·일일 한도·키 가림 등 16개 (가짜 네트워크 사용, 실제 호출 없음)
- 저장 계층은 브라우저 검수 페이지 `tests/storage-harness.html`로 확인합니다. 저장소 루트를 정적 서버로 열고 `/tests/storage-harness.html`에 접속하세요.
- 2026-10-18 실제 브라우저 검수: 작업 생성·저장·새로고침 복원, 이미지 업로드, 스케치 저장, 백업 내려받기·가져오기 왕복, 가짜 키로 Gemini·OpenAI에 실제 도달(HTTP 400·401 응답) 확인, 유료 확인창 확인. 실제 유료 생성은 하지 않았습니다.

## 한계
- 실제 AI 이미지 생성·변환 품질과 비용은 검수하지 않았습니다.
- 브라우저 저장소는 브라우저가 공간 부족 시 지울 수 있습니다. 설정 화면에서 "영구 보관 요청" 허용 여부를 볼 수 있습니다.
- 두 탭에서 같은 작업을 동시에 고치면 저장 충돌 확인창이 뜹니다.
- 서버판의 필드 단위 상세 검증은 옮기지 않았습니다. 백업 파일은 출처를 확인하고 가져오세요.

# 나의 창작실 정적판 v1.0

서버와 로그인 없이 **브라우저 안에 작업을 저장**하는 개인용 창작 웹앱입니다. 화면 파일만 올리면 되므로 Cloudflare Pages 같은 무료 정적 호스팅에 배포할 수 있습니다. 서버판(Node + SQLite)은 같은 저장소의 루트에 그대로 있습니다.

## 서버판과 달라진 점
| | 서버판 | 정적판 (이 폴더) |
|---|---|---|
| 작업·이미지 저장 | 서버 디스크 | **이 브라우저의 IndexedDB** |
| 로그인 | 소유자 계정 | 없음 |
| AI 키 | 서버에 암호화 보관 | **이 브라우저에 보관(암호화 없음)** 또는 탭을 닫으면 삭제 |
| AI 호출 | 서버가 중계 | **브라우저가 Google·OpenAI로 직접 호출** |
| 기기 간 이어쓰기 | 같은 주소로 접속 | **자동 동기화 없음, 백업 파일로 옮김** |
| 호스팅 비용 | 월 몇 달러 이상 | 무료 정적 호스팅 가능 |

## 꼭 알아둘 점
- 작업은 **이 기기의 이 브라우저에만** 있습니다. 사이트 데이터를 지우거나 다른 브라우저로 열면 보이지 않습니다. 중요한 작업은 작업 화면의 "백업"으로 파일을 내려받아 두세요.
- 다른 기기에서는 "백업 파일 가져오기"로 불러옵니다. 서버판에서 내려받은 백업도 가져올 수 있습니다.
- 사이트 주소는 공개 주소입니다. 하지만 작업 내용은 각자의 브라우저에만 있고 서버로 전송되지 않으므로 다른 사람이 내 작업을 볼 수 없습니다.
- AI 키는 암호화되지 않은 채 브라우저에 저장됩니다. 제공자 화면에서 **사용 한도(예산)를 정한 제한 키**를 만들어 쓰고, 공용 PC에서는 "이 브라우저에 키 기억하기"를 끄거나 사용 후 키를 삭제하세요. 작업 백업 파일에는 키가 들어가지 않습니다.
- 하루 AI 요청 한도는 이 브라우저에서 세는 횟수일 뿐 금액 상한이 아닙니다.

## 이미지 모델 선택과 무료 기준
이미지 모델은 한 가지로 고정되지 않습니다. 각 도구 화면의 생성 버튼 위에서 **이미지 모델과 품질**을 고르면 그 요청에만 적용되고, 도구별로 저장됩니다. 설정의 'AI 연결 설정'에서는 기본 모델과 목록에 없는 모델 ID(직접 입력)를 정할 수 있습니다. 생성 전 확인창에 선택한 모델·품질·크기와 금액 어림이 표시되고, 이 요청이 무료 구간이 없는 유료 요청임을 분명히 안내합니다.

확인 기준일 **2026-10-18**, 출처: OpenAI 공식 모델 문서(developers.openai.com/api/docs/models/모델ID). 금액은 USD, 장당, 입력 이미지 비용 별도입니다. 표의 크기 열은 1024×1024 / 1536×1024 또는 1024×1536.

| 모델 ID | 설명 | low | medium | high | 품질 옵션 |
|---|---|---|---|---|---|
| gpt-image-1 | 이전 세대 | $0.011 / $0.016 | $0.042 / $0.063 | $0.167 / $0.25 | low·medium·high·auto |
| gpt-image-1-mini | 가장 저렴 | $0.005 / $0.006 | $0.011 / $0.015 | $0.036 / $0.052 | low·medium·high·auto |
| gpt-image-1.5 | 이전 세대 · 지시 이행 향상 | $0.009 / $0.013 | $0.034 / $0.05 | $0.133 / $0.2 | low·medium·high·auto |
| gpt-image-2 | 표준 최신 | 토큰 기준 | 토큰 기준 | 토큰 기준 | low·medium·high·auto |
| gpt-image-2.5-sunburst | 편집 정밀도 최우선 | 토큰 기준 | 토큰 기준 | 토큰 기준 | + xhigh·max |
| gpt-image-2.5-flare | 빠른 일상용 | 토큰 기준 | 토큰 기준 | 토큰 기준 | + xhigh·max |

- **gpt-image-2와 2.5 계열은 토큰 기준 요금**(이미지 출력 100만 토큰당 $30, 이미지 입력 $8, 2.5는 GPT Image 2와 토큰 요금 동일)이라 장당 금액을 어림하지 않습니다. OpenAI 공식 계산기에서 확인하세요.
- 품질 auto는 실제 품질이 정해지지 않아 금액이 확정되지 않습니다.
- 참조 이미지를 보내는 변환은 입력 이미지 토큰 비용이 더해집니다.
- **무료 기준(앱 안의 '무료 기준 안내'와 같은 내용)**: 앱 자체·호스팅·저장·편집·스케치·장면 분할·백업·내보내기·프롬프트 복사는 무료(AI 호출 없음). OpenAI 이미지 모델은 무료 구간이 없는 유료. Google Gemini 텍스트 API는 AI Studio에 무료 구간이 있지만 모델·한도는 계정·시점에 따라 다릅니다(제3자 정리 기준). Gemini 이미지 모델은 유료이며 이 앱은 아직 지원하지 않습니다.
- 앱의 하루 한도는 이 브라우저의 횟수일 뿐 금액 상한이 아닙니다. 금액 상한은 OpenAI 프로젝트의 월 한도로 설정하세요.
- 코드: `public/model-catalog.js`(목록·금액 어림·무료 기준 문구의 유일한 출처), 테스트 `tests/model-catalog.test.mjs`.

## 기능
디렉터 캔버스(스케치·화풍), 시그니처 이미지 생성, 실사 애니화, 애니 실사화, 멀티 이미지 에디터, 스토리보드, 그리고 추가 기능인 상세페이지 제작, 이미지·썸네일 편집, 대본·장면, 프롬프트 작업대. 직접 편집·스케치·장면 분할은 AI 없이 쓸 수 있습니다. AI 생성·변환은 실행 전에 Google·OpenAI로 직접 전송되는 내용과 비용을 확인합니다.

## 내 PC에서 미리보기
Node.js 20 이상이 있으면 됩니다. 별도 설치는 없습니다.
1. 이 폴더에서 `node tools/serve.mjs` 를 실행합니다.
2. 브라우저에서 http://127.0.0.1:4400 을 엽니다. 실제 배포와 같은 보안 헤더(`public/_headers`)가 적용됩니다.

## 배포
현재 배포 주소: https://my-studio-ers.pages.dev (Cloudflare Pages Direct Upload). 주소를 바꾸면 저장된 작업이 보이지 않으므로 바꾸기 전에 백업을 받으세요. 절차는 `DEPLOY-PAGES.md`를 보세요. 빌드 명령은 없고, `public` 폴더 전체가 배포 대상입니다.

## 검증
- `npm test` (`node --test tests/*.test.mjs`): AI 요청 형식·일일 한도·키 가림·모델/품질 선택·금액 어림 등 29개 (가짜 네트워크 사용, 실제 호출 없음)
- 저장 계층은 브라우저 검수 페이지 `tests/storage-harness.html`로 확인합니다. 저장소 루트를 정적 서버로 열고 `/tests/storage-harness.html`에 접속하세요.
- 2026-10-18 실제 브라우저 검수: 작업 생성·저장·새로고침 복원, 이미지 업로드, 스케치 저장, 백업 내려받기·가져오기 왕복, 가짜 키로 Gemini·OpenAI에 실제 도달(HTTP 400·401 응답) 확인, 유료 확인창 확인. 실제 유료 생성은 하지 않았습니다.

## 한계
- 실제 AI 이미지 생성·변환 품질과 비용은 검수하지 않았습니다.
- 브라우저 저장소는 브라우저가 공간 부족 시 지울 수 있습니다. 설정 화면에서 "영구 보관 요청" 허용 여부를 볼 수 있습니다.
- 두 탭에서 같은 작업을 동시에 고치면 저장 충돌 확인창이 뜹니다.
- 서버판의 필드 단위 상세 검증은 옮기지 않았습니다. 백업 파일은 출처를 확인하고 가져오세요.

# Phase 3a 상세페이지 제작 기능 이식 분석

작성: 2026-10-18 · 근거: 사용자 본인 저장소 https://github.com/cholmi1/Make--Details-Page (README.md, index.html 단일 파일 앱)

## 원본 앱 구조
- 1단계 자료 등록: 이미지/PDF 최대 8개(첫 번째 = 대표), 모델 이미지(선택), 추가 정보, 고객 후기(xlsx/csv/tsv) → Gemini 후기 분석.
- 2단계 생성 설정: 구성 템플릿 6종(기본형, 구매저항 해소형, 비교/근거 강화형, 사용 시나리오형, 스토리브랜드 판매 서사, 모바일 집중형), 섹션 수, 카피 언어, 비율(2:3/1:1/3:2), 스타일 8종, 텍스트편집/통이미지 모드, 모델 설정, 톤 → Gemini가 JSON으로 섹션·카피 설계.
- 3단계 편집 & 결과: 섹션 목록(추가·복제·삭제·순서), 섹션 카피, 텍스트 레이어(폰트·크기·굵기·정렬·색·줄 간격·폭·그림자·배경 박스·숨김), 캔버스 드래그, OpenAI 이미지 생성(전체/개별), 내 이미지로 교체, 섹션 PNG·통합 이미지·전체 ZIP(1080px).
- 저장: 브라우저 IndexedDB, API 키 localStorage, 브라우저에서 Google·OpenAI API 직접 호출.

## 나의 창작실 이식 방식
| 원본 기능 | 이식 결과 |
|---|---|
| 자료 등록 | 자료함 연동(제품 이미지 8개·대표 지정·순서), 모델 이미지, 추가 정보. PDF는 미지원(이미지로 저장 후 등록 안내) |
| 후기 분석 | CSV/TSV 로컬 파싱 + 로컬 키워드·긍정/부정 문장 정리(AI 아님), 결과 수정 가능. xlsx는 CSV 저장 안내 |
| AI 섹션 설계 | (1) 템플릿 초안(AI 아님) (2) 원본과 같은 Gemini 설계 요청문 복사 → Gemini 웹 사용 → 결과 JSON 붙여넣기로 섹션 변환 (3) 직접 호출은 AI 미연결 |
| 섹션 편집·텍스트 레이어 | 동일 기능 구현, 폰트는 외부 웹폰트 없이 로컬 글꼴 4종 매핑 |
| 섹션 이미지 생성 | 원본과 같은 영어 이미지 프롬프트 복사, 결과 이미지는 자료함에서 지정. 직접 생성은 AI 미연결 |
| 내보내기 | 섹션 PNG, 통합 PNG(최대 높이 32000px), ZIP(외부 라이브러리 없이 자체 ZIP 작성기) + copy.txt |
| 저장 | 브라우저 IndexedDB 대신 기존 서버 저장·버전 충돌·백업/복원 체계 사용 |

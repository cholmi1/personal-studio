# Objective
로컬에서 인증·서버 영속 저장·자료 보관·스토리보드·썸네일을 실제 작동시킨다.

## Task 1 / Backend
API_CONTRACT에 따른 단일 소유자 인증, SQLite 프로젝트/세션, 검증된 이미지, 백업/복원 구현. tests/api.test.mjs로 인증 차단·설정 재등록 차단·저장·충돌·이미지·재시작·백업·요청 출처 검증.

## Task 2 / Frontend
원본 디자인의 한국어 개인 작업실. API 계약을 사용해 인증/프로젝트/대본과 명확한 로컬 장면 분할/이미지 캔버스/텍스트 레이어/PNG 출력/백업을 실제 연결. 저장실패·연결 전 AI 상태 표시.

## Task 3 / Integration
브라우저에서 별도 검수용 계정과 데이터로 프로젝트/자료/레이어 저장·재로드·PNG·반응형 화면을 검사. 본인용 실행 인스턴스는 초기 계정 미설정으로 시작.

## Verification
시크릿·런타임 .data를 제외한 소스 ZIP. 노드 테스트·문법 검사 및 실제 브라우저 검수. 미완성 AI·미배포·원격 사용 미검증을 정확히 보고.

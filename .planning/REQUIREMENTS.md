# Requirements: 나의 창작실

Defined: 2026-10-18

## v1 Requirements
- [x] AUTH-01: 최초 소유자 계정 생성, 이후 신규 가입 차단, 로그인·로그아웃·서버 세션.
- [x] AUTH-02: 비밀번호 해시, HttpOnly 쿠키, 요청 출처·파일 업로드 검증.
- [x] SAVE-01: 프로젝트 생성·수정·삭제와 서버 영속 저장, 수정 버전 충돌 감지.
- [x] STORY-01: 대본 편집·명시적인 로컬 장면 분할·장면별 내레이션/프롬프트·순서 편집.
- [x] MEDIA-01: PNG/JPEG/WebP 업로드·보관과 개별 다운로드.
- [x] EDIT-01: 이미지 배치·배경색·비율·독립 텍스트 레이어를 편집하고 PNG로 출력.
- [x] BACKUP-01: 프로젝트와 원본 이미지를 포함한 JSON 내보내기·가져오기.
- [ ] UX-01: 한국어·키보드·모바일 폭에서 사용 가능, 저장/오류/미연결 상태 표시.
- [x] AI-01: 유료 호출 없이 미연결 상태 표시. 실제 생성 연결은 승인·키·모델 확인 후.
- [ ] DEPLOY-01: 다기기용 HTTPS 서버 배포는 사용자 승인 후 별도 검증.

UX-01 보완: 한국어·키보드·저장/오류/미연결 표시 구현과 데스크톱 검수는 완료. 모바일 대응 CSS는 있으나 실제 휴대폰 검수는 Phase 3 대기.

## v0.2 Requirements (Phase 2.5, 2026-10-18)
- [x] STORY-02: 등장인물 레퍼런스, 목표 장면 수 분할, 장면별 이미지·인물·이미지 프롬프트, 보드 보기, 프롬프트 텍스트·CSV, 스토리보드 PNG.
- [x] PROMPT-01: 분류 칩 기반 프롬프트 작업대(비율·심도·시드·Negative), 복사, 장면 일괄 적용. AI 호출 없음.
- [x] EDIT-02: 이미지 레이어 8개 합성, 비율 5종, 글자 외곽선, 합성 PNG.
- [x] SKETCH-01: 로컬 스케치 패드와 자료함 저장, 레이어 추가.
- [x] AI-02: AI 필수 기능 8종 연결 현황 표시(미연결, 가짜 결과 없음).

## v0.3 Requirements (Phase 3a, 2026-10-18)
- [x] DETAIL-01: 상세페이지 자료 등록(제품 8·모델·추가 정보·후기 CSV 로컬 정리).
- [x] DETAIL-02: 템플릿 6종 설정, 템플릿 초안, 외부 AI 설계 요청문 복사·JSON 결과 변환.
- [x] DETAIL-03: 섹션·텍스트 레이어 편집, 1080px 섹션/통합 PNG, ZIP 내보내기.
- [ ] DETAIL-AI: Gemini 자료 분석·카피 설계, 섹션 이미지 생성 직접 연결(키·비용·외부 전송 승인 필요).

## v2 Requirements
이미지 생성/편집 모델 연결, 대본 AI 작성, TTS, 영상 생성과 편집·합성, 비밀번호 복구, 공개 공유.

## Traceability
Phase 1: AUTH-01, AUTH-02, SAVE-01, BACKUP-01.
Phase 2: STORY-01, MEDIA-01, EDIT-01, UX-01, AI-01.
Phase 3: DEPLOY-01 및 실제 생성 제공자 연결 검수.

## Out of Scope
타 서비스 내부 코드·자산 복제 및 접근 제한 우회. 개인 자료의 무단 외부 업로드. CVT200 및 회사 마케팅 기능.

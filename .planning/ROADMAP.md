# Roadmap: 나의 창작실

## Phases
- [x] Phase 1: 인증·프로젝트·자료의 서버 영속 저장과 백업.
- [x] Phase 2: 스토리보드와 이미지·썸네일 편집 화면 및 데스크톱 로컬 브라우저 검수.
- [ ] Phase 3: 승인된 AI 제공자 연결, HTTPS 비공개 배포와 실제 다기기 검수.

## Success Criteria
1. 새로고침·서버 재시작 후 프로젝트와 이미지가 보존된다. 인증 전 프로젝트·이미지에 접근할 수 없다.
2. 수동 대본 수정, 로컬 분할, 텍스트 레이어 편집과 PNG 내보내기가 실제 동작한다. AI 결과를 흉내 내지 않는다.
3. Phase 3은 계정·호스팅·API키·비용·외부 업로드 승인 후 진행한다. 현재는 대기.

## Progress
Phase 1 complete; Phase 2 desktop implementation/developer QA complete; user acceptance and actual mobile/device verification pending; Phase 3 blocked pending separate approval and credentials.

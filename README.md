# 나의 창작실 v0.5

개인용 창작 웹앱의 기능별 전용 작업실 버전입니다. 외부에 아직 배포하지 않았습니다. Walter의 소스·디자인·전용 프롬프트를 복제하지 않았습니다.

> **정적판 안내 (2026-10-18)**: 서버와 로그인 없이 브라우저에 저장하고 Cloudflare Pages 같은 무료 정적 호스팅에 배포하는 버전은 [`static-edition/`](static-edition/) 폴더에 있습니다. 이 루트의 README는 서버판(Node + SQLite) 설명입니다.

## 현재 목표
내 자료와 대본·스토리보드, 이미지/썸네일 편집 상태를 하나의 서버에 저장합니다. 이후 비공개 HTTPS 서버를 배포하면 집·회사·휴대폰이 같은 계정과 저장소를 사용하도록 설계합니다. **현재는 외부에 배포하지 않았으므로 다른 기기에서 이어 쓰기가 아직 작동하지 않습니다.**

## 실행
1. Node.js 24.15 이상 24.x가 필요합니다. 현재 작업 PC에서는 24.20.0을 확인했습니다. 별도 npm 패키지 설치는 필요하지 않습니다.
2. ZIP 파일을 받았다면 압축을 풀고 `시작.cmd`를 실행합니다. 또는 이 폴더에서 `node src/server.mjs`를 실행합니다.
3. 콘솔에 표시된 로컬 주소를 브라우저에서 엽니다. 기본 주소는 http://127.0.0.1:4318 입니다.
4. 첫 화면에서 본인이 사용할 이름·이메일 형식의 로그인 ID·12자 이상 비밀번호를 직접 정합니다. 실제 이메일 발송·가입 인증은 하지 않습니다. 최초 소유자 설정 후 추가 회원가입은 차단됩니다.
5. 사용을 끝내면 서버가 실행 중인 명령창에서 Ctrl+C를 누릅니다.

## 데이터 보관
- `시작.cmd`는 현재 사용자에게 Aside 계정 폴더가 있으면 `%USERPROFILE%\.aside\u\0\personal-studio-data`에 저장합니다. 폴더가 없으면 압축을 푼 앱 폴더의 `.data`를 사용합니다. 실행창에 실제 데이터 위치가 표시됩니다. 폴더 삭제·교체 전에 프로젝트 백업을 내려받으세요.
- DATA_DIR 환경변수로 별도 데이터 폴더를 지정할 수 있습니다. `node src/server.mjs`를 직접 실행하면 DATA_DIR 미설정 시 앱 폴더의 `.data`를 쓰므로 같은 작업을 이어가려면 `시작.cmd`를 사용하세요. Aside 로컬 실행 데이터는 `%USERPROFILE%\.aside\u\0\personal-studio-data`를 사용하며 소스 코드와 분리합니다. GitHub 저장소에는 소스만 보관하며, 계정·프로젝트·개인 이미지 데이터는 업로드하거나 기기 간 자동 동기화하지 않습니다.
- 프로젝트 백업 JSON에는 등록 이미지와 편집 상태가 포함됩니다. 로그인 정보·비밀번호는 포함하지 않습니다. 개인 사진이 포함될 수 있으므로 백업을 안전하게 보관하세요.
- 브라우저 새로고침과 서버 재시작에도 저장한 프로젝트를 이어 쓸 수 있도록 서버 저장소를 사용합니다. 저장 버튼을 누르지 않은 편집은 보관되지 않습니다.
- 비밀번호 찾기·이메일 복구는 아직 없습니다. 본인 비밀번호를 안전하게 관리하세요.

## v0.5: 첨부 참조 기준 기능별 작업실 재구성 (2026-10-18)
- 기존 여행·이야기 같은 소재 분류를 핵심 진입점으로 쓰지 않고, 홈과 왼쪽 메뉴에 6개 창작 도구를 배치했습니다. 예시 작업은 자동 생성하지 않습니다.
- 디렉터 캔버스: 화풍 선택, 직접 스케치·이미지 업로드, 장면 묘사, AI 이미지 요청.
- 시그니처 이미지 생성: 프롬프트, 비율·출력 크기, 배경 심도, 시드 힌트, 결과 저장.
- 실사 애니화 / 애니 실사화: 원본 업로드와 변환 결과를 나란히 표시하고 이미지 API에 원본을 참조로 전송합니다.
- 멀티 이미지 에디터: 멀티 캔버스·메인+참조 모드, 최대 8개 영역의 위치·크기·이미지 배치. 현재 제공자 요청은 최대 4개 서로 다른 참조 이미지까지 지원합니다.
- 스토리보드: 등장인물 레퍼런스, 대본, 장면 수, 로컬 분할·수정 및 AI 보조.
- 상세페이지 제작은 별도 추가 기능으로 유지했습니다. 기존 대본·장면, 이미지·썸네일, 프롬프트, 자료·메모 탭도 제거하지 않았습니다.
- 기능별 입력·참조·결과 ID를 서버 프로젝트 상태와 백업에 저장합니다. 실제 이미지 출력 크기·시드 재현성은 제공자 API 지원 범위를 따르며 화면 힌트만으로 보장하지 않습니다.
- 참조 서비스의 전용 모델·프롬프트·크레딧 과금 체계를 복제하지 않습니다. 이미지 생성·변환은 기존 OpenAI 경로, 텍스트 보조는 Gemini 경로를 사용합니다. 실행마다 외부 전송·비용 확인을 거칩니다.
- 이번 개편에서 실제 유료 생성·변환 품질은 검수하지 않았습니다.

## v0.4 추가 기능: API 키 테스트·배포 준비 (2026-10-18)
- 로그인 후 **AI 연결**에서 Gemini·OpenAI 키와 모델을 설정합니다. 키 입력만으로 연결 성공을 보장하지 않으며, 연결 확인 및 실제 생성은 별도입니다.
- Gemini: 후기 분석·상세페이지 설계·대본 다듬기·장면 프롬프트. OpenAI: 섹션·장면·프롬프트 이미지 생성, 참조 이미지 편집, 캔버스 배경.
- 키는 서버에 AES-256-GCM 암호화 보관(환경변수 키 우선), 브라우저 저장소·작업 백업·GitHub에는 넣지 않습니다. 암호화는 서버 침해에 대한 완전한 보호가 아닙니다.
- 호출마다 문구·선택 사진의 외부 전송과 과금 가능성을 확인합니다. 한국시간 일일 텍스트30·이미지10회 기본, 실패 시도도 포함. 금액 상한은 아니며 제공자에서 예산·결제를 별도 관리하세요.
- Docker·Railway·Render 영구 디스크 단일 서버 설정, 원격 최초 설정 토큰, HTTPS·Secure 쿠키·Origin 검증. 실제 배포·유료 호출은 수행하지 않았습니다.
- **초보자용 키 적용·배포 순서: [DEPLOY.md](DEPLOY.md)**. Docker 미설치로 컨테이너 빌드 검수는 미완료입니다. Vercel·Workers 직접 배포는 지원하지 않습니다.

- 생성 설정: 구성 템플릿 6종, 섹션 수, 카피 언어, 비율 3종(2:3·1:1·3:2), 스타일 8종, 텍스트편집/통이미지 모드, 모델 설정, 톤.

- 편집: 섹션 추가·복제·삭제·순서, 카피·포인트, 섹션 이미지(자료함), 이미지 프롬프트 복사, 텍스트 레이어(글꼴 4종·크기·굵기·정렬·색·줄 간격·폭·그림자·배경 상자·숨김), 미리보기에서 끌어 옮기기.
- 내보내기: 1080px 섹션 PNG, 통합 PNG, 전체 ZIP(섹션 PNG + 통합 PNG + copy.txt).
- 작업 종류에 '상세페이지'가 추가되었고, 이 종류의 작업은 상세페이지 탭으로 열립니다.

## 1차 기능 범위
프로젝트 관리, 대본/스토리보드의 수동 편집과 명확히 표시한 로컬 분할, PNG/JPEG/WebP 자료 보관, 이미지/썸네일 캔버스와 텍스트 레이어 편집, PNG 다운로드, 프로젝트 백업/복원.

## 아직 연결하지 않은 기능
- 음성·영상 생성은 미구현. Gemini/OpenAI 텍스트·이미지 호출은 v0.4에서 연결했지만 사용자 키의 실제 권한·모델·품질·요금은 아직 미검증입니다.
- 실제 API 키는 사용자 본인이 입력하고 실행을 확인해야 합니다. Google Pro 구독이 외부 앱의 API 사용량과 자동으로 통합된다고 가정하지 않습니다.
- 원격 HTTPS 배포·클라우드 저장소·실제 다기기 동기화. 공개 서비스가 아닌 본인 전용으로 진행하며, 호스팅·계정·비용·외부 업로드는 별도 확인합니다.
- 상용 공개 운영 전 추가 보안 검토·HTTPS·백업·복구·디스크 용량·모니터링·로그인 복구가 필요합니다. 영구 볼륨·HTTPS·설정 토큰을 확인한 뒤 본인 전용으로 배포하세요.
